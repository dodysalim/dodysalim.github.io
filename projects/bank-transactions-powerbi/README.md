## 📌 Resumen en 30 segundos

| | |
| --- | --- |
| **🎯 Problema** | Distinguir registros, transacciones y valor para comparar sectores y ubicaciones mes a mes. |
| **🛠️ Solución** | Modelo en Power BI con dimensiones de fecha, sector y ubicación, y agregados publicados en JSON. |
| **📈 Entregables** | Vista web interactiva con filtros, KPIs, gráfica mensual y tabla de valores exactos. |

## 🔎 Alcance

La [vista interactiva del portafolio](https://dodysalim.github.io/#analisis) consume el [archivo de agregados](../../bank-data.json) de este repositorio. Permite filtrar por sector y ubicación y revisar valores mensuales exactos.

Los agregados representan 1.004.480 registros. El número de registros y la cantidad de transacciones son medidas distintas. La moneda y el origen institucional no están especificados.

Los archivos PBIP y los CSV originales del modelo Power BI están pendientes de incorporarse. Las comprobaciones de claves y nulos del caso original no se pueden repetir a partir de estos agregados.
