## Organización para GitHub

La entrega actual separa artefactos finales, datos, código, scripts y documentación. Las fuentes originales y su documentación se copian íntegramente a `historico/entrega_anterior`. Esta carpeta conserva la estructura que necesitan los iniciadores históricos.

Los archivos operativos generados durante ejecuciones anteriores no forman parte del histórico versionado. Las nuevas ejecuciones crean sus registros en `.local`, excluida de Git. Los CSV y el Excel de `datos` son copias de las fuentes históricas para que el Avance 4 tenga rutas claras.

La documentación original menciona nueve páginas para una versión anterior. La entrega actual contiene diez, incluida la portada. Los datos de arquitectura y fórmulas de esta documentación se extrajeron del modelo actual, sin sustituir las notas históricas.

No se creó un Avance 5: esta reorganización documenta y distribuye el Avance 4.
